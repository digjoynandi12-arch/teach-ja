## 進め方の見取り図（仮。学習記録を見て毎回見直す）

1. ステージングとコミットの違い（0001、作成済み）
2. 履歴を読む: `git log`、`git show`、コミットの単位とメッセージ（0002、作成済み。結果は未報告）
3. ブランチを切る・切り替える
4. リモートとGitHub: clone、push、pull
5. プルリクエストを出す
6. レビューの指摘を反映する
7. コンフリクトを意図的に起こして解消する（怖さを減らす）
8. 通しリハーサル（ブランチ→プルリクエスト→レビュー→マージ）

間隔をあけた復習として、各回の冒頭に前の回のクイズを2問ほど混ぜる。
