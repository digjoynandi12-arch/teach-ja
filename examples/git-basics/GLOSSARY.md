# Git 用語集

GitとGitHubでのチーム開発を学ぶこのワークスペースで使う、用語と表記の決まりです。

## 用語

**作業ディレクトリ（working directory）**:
今、編集しているファイルそのものが置かれている場所。
_避ける表現_: ワーキングツリー、作業ツリー、ワークツリー

**ステージングエリア（staging area）**:
次のコミットに入れる内容の置き場。「次のコミットの下書き」。
_避ける表現_: ステージング・エリア、インデックス、ステージ

**ステージする（stage）**:
作業ディレクトリにあるファイルの、その時点の内容をステージングエリアに写すこと。`git add` で行う。
_避ける表現_: アドする、追加する、ステージングする

**コミット（commit）**:
ステージングエリアの内容を、メッセージ付きで履歴に記録したもの。またはその操作。
_避ける表現_: 確定、セーブ、保存

## 表記の注意

- Pro Git 日本語訳は「ステージング・エリア」と書き、Gitの公式リファレンスは「インデックス（index）」とも呼ぶ。どちらもこの用語集のステージングエリアと同じもの。
- `git status` の "working tree" は作業ディレクトリのこと。
