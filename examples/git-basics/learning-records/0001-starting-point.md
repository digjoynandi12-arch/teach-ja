# 出発点: add と commit は打てるが、意味はあいまい

`git add` と `git commit` は使ったことがあるが意味はよくわかっておらず、ステージングとコミットの違いがあいまいだと本人が申告した（2026-11-15）。ターミナルは少しだけ使える。コンフリクトが怖いとのこと。ブランチ、リモート、プルリクエストの経験は申告がないので、未経験として扱う。

## 今後への影響

- 最初のレッスンは「3つの場所」とステージングの意味から始める。コマンドの打ち方そのものは教え直さなくてよい。
- コンフリクトは、ブランチとマージを理解したあとに、練習用リポジトリで意図的に起こす形で扱う。
