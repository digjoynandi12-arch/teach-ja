ステージングとコミット

変更が今どこにあるかを確かめ、選んだ分だけをコミットするための早見表です。

3つの場所

作業ディレクトリ今、編集しているファイル
git add
ステージングエリア次のコミットに入れる内容
git commit
リポジトリコミットが積み重なった履歴

コミットが記録するのは、ステージングエリアの内容です。git add したあとに編集した分は、もう一度 git add するまでコミットに入りません。

コマンド

コマンドすること
git status変更が今どこにあるかを表示します。迷ったら最初に打ちます。
git add ファイル名そのファイルの今の内容をステージします。
git commit -m "メッセージ"ステージングエリアの内容を、メッセージ付きで履歴に記録します。
git diff作業ディレクトリとステージングエリアの差分。まだステージしていない変更です。
git diff --stagedステージングエリアと最後のコミットの差分。次のコミットに入る変更です。

git status の読み方

見出し変更のある場所コミットに入れるには
Changes to be committedステージングエリアこのまま git commit
Changes not staged for commit作業ディレクトリだけgit add してから git commit
Untracked files作業ディレクトリだけ（新しいファイル）git add してから git commit
nothing to commit3つの場所が同じ内容コミットするものはありません

同じファイルが上の2つの欄に同時に出るのは、ステージしたあとにもう一度編集したときです。

コミットする前の確認

  1. git status で、入れたいファイルだけが Changes to be committed にあることを確かめます。
  2. git diff --staged で、入る内容を読みます。
  3. git commit -m "…" で記録します。
