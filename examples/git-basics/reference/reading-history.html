履歴を読む・コミットを分ける

履歴を読むコマンドと、読みやすいコミットを作るための早見表です。

履歴を読むコマンド

コマンド見えるもの
git logコミットを新しい順に。コミットハッシュ、作者、日時、コミットメッセージ。
git log --oneline1コミットを1行で。短いハッシュとメッセージの1行目。
git log --stat各コミットで変更されたファイルの一覧と、追加・削除された行数。
git log -p各コミットの差分そのもの。
git log -2直近の2件だけ。--oneline、--stat、-p と組み合わせられます。
git log -- ファイル名そのファイルを変更したコミットだけ。
git show最新のコミット1つの、メッセージと差分。
git show ハッシュ指定したコミット1つの、メッセージと差分。

出力が長いと1ページずつ表示されます。スペースキーで次のページ、q で終了です。

git log の1コミット分の読み方

行意味
commit 3f2a9c1…コミットハッシュ。コミット1つずつに付く、重複しない名前。
Author:コミットした人の名前とメールアドレス。
Date:コミットした日時。
字下げされた行コミットメッセージ。

コミットの分け方

  • 1つの目的に、1つのコミット。バグ修正と誤字の修正は、別のコミットにします。
  • 分ける基準は、ファイルではなく目的です。1つの目的が複数のファイルにまたがるなら、同じコミットに入れます。
  • 今回の目的に合う変更だけを git add し、git diff --staged で確かめてからコミットします。

コミットメッセージ

  • 1行目は、変更の短い概要。どこの何を変えたのかが、差分を開かなくてもわかるように書きます。
  • 詳しい説明が必要なら、空行を1つはさんで続けます。
  • 言語や書式の決まりは、チームのルールに従います。
